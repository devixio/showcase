هايبرلاند

compositWayland مع Catppuccin Mocha، تمويه، رسوم متحركة، اختصارات مخصصة، وتوجيه مساحات العمل.

monitor = DP-1, 1920x1080@180, 0x0, 1
general {
    gaps_in = 6
    gaps_out = 12
    border_size = 4
    col.active_border = rgba(89B4FAFF) rgba(CBA6F7FF) 135deg
}
decoration {
    rounding = 0
    active_opacity = 0.95
    blur { size = 8 passes = 4 }
}

فِش

إعداد الشل مع سمة Catppuccin، موجه Tide v6، وعرض fastfetch عند بدء التشغيل.

fish_config theme choose catppuccin_mocha
set -g tide_left_prompt_items pwd git newline character
set -g tide_right_prompt_items status cmd_duration context jobs node python
function fish_greeting
    fastfetch
end

ألكرتي

محاكي طرفية مسرّع بالـ GPU مع Catppuccin Mocha وخط JetBrainsMono Nerd وشفافية 80%.

[window]
opacity = 0.80
padding = { x = 12, y = 12 }

[font]
size = 12.0
[font.normal]
family = "JetBrainsMono Nerd Font"

[colors.primary]
background = "#1E1E2E"
foreground = "#CDD6F4"

ووفي

مشغل تطبيقات Wayland مع سمة "الزجاج السائل" Catppuccin، تمويه، وزوايا حادة.

width = 640
height = 460
location = center
prompt = Search...
allow_markup = true
show = drun

/* style.css */
window {
    background: rgba(30, 30, 46, 0.80);
    border: 1px solid #CBA6F7;
}

GTK 3.0

سمة GTK مع Catppuccin-Mocha، تجاوزات CSS مخصصة لـ Thunar، ومؤشرات Breeze.

[Settings]
gtk-theme-name = Catppuccin-Mocha
gtk-icon-theme-name = Catppuccin-Mocha-Alt
gtk-cursor-theme-name = breeze_cursors
gtk-font-name = Noto Sans 10
gtk-application-prefer-dark-theme = true

Qt5 / Qt6

سمة Qt عبر qt5ct/qt6ct مع محرك Kvantum ونظام ألوان Catppuccin-Mocha.

[Appearance]
icon_theme = Catppuccin-Mocha-Alt
color_scheme_path = catppuccin-mocha.conf

[Interface]
style_engine = kvantum

ثونار

مدير الملفات مع إجراءات مخصصة، عرض الأيقونات، وإعدادات XFCE4 لسلوك النافذة.

<!-- إجراء مخصص: فتح الطرفية هنا -->
<action>
    <icon>utilities-terminal</icon>
    <name>فتح الطرفية هنا</name>
    <command>exo-open --working-directory %f \
      --launch TerminalEmulator</command>
</action>
